# User guide

The user guide of ekphrasis serves an author who installs the plugin and writes YAML notes.

- [Installation](installation.md): to install the plugin in a vault, and to avoid a conflict with another plugin that opens YAML notes.
- [Authoring rich content in YAML](authoring-yaml.md): to choose the scalar style that preserves Markdown, formulas and links in a value.
